# Helpdesk App

An enterprise helpdesk ticket-management application built to practice:

- Java 8
- Spring Boot
- REST APIs
- Microsoft SQL Server
- Maven
- Angular
- Logging and error handling
- Authentication and authorization
- Windows Server deployment
- Apache Tomcat
- IIS reverse proxy

## Main folders

- backend - Java and Spring Boot API
- frontend - Angular user interface
- database - SQL Server scripts
- documentation - Requirements and technical documentation
- deployment - Deployment scripts and instructions
